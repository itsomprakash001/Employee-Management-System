# 👨‍💼 Employee Management System

A **Full-Stack MERN (MongoDB, Express.js, React.js, Node.js)** web application for managing employees, departments, salaries, and leave requests. The system provides separate dashboards for **Administrators** and **Employees** with secure authentication and role-based access control.

---

## 🌟 Project Highlights

- 🔐 Secure JWT Authentication
- 👥 Role-Based Access Control
- 📊 Admin & Employee Dashboards
- 🏢 Department Management
- 👨‍💼 Employee Management
- 📝 Leave Management System
- 💰 Salary Management
- 🔒 Change Password Feature
- 📤 Local Image Upload & Storage
- ⚡ RESTful API with Express.js
- 🎨 Responsive UI with Tailwind CSS
- 🚀 Built using MERN Stack

---

## ▶️ Run Locally



###  Start the Backend

```bash
cd server
npm install
npm start
```

###  Start the Frontend

```bash
cd client
npm install
npm run dev
```
